# Projeto Entregador — PET Engenharia de Computação UFC

## Sobre o projeto

Esta branch corresponde à minha parte do projeto desenvolvido durante o **processo seletivo do PET Engenharia de Computação — edição 2026.2**.

O projeto consiste no desenvolvimento, inteiramente no **Tinkercad**, de um sistema robótico capaz de realizar o **transporte automatizado de cargas entre quatro estações possíveis**.

O robô foi projetado para se deslocar entre as estações e realizar o transporte da carga de forma autônoma, integrando diferentes recursos de automação e controle.

## Principais funcionalidades

* **Transporte de cargas** entre quatro estações possíveis;
* **Navegação entre estações** por meio do sistema de locomoção do robô;
* **Detecção de obstáculos**, permitindo identificar obstáculos durante o percurso;
* **Sistema de abertura por senha**, utilizado para controlar o acesso à carga;
* **Painel LCD**, utilizado para apresentar informações e permitir o acompanhamento do sistema;
* Integração entre sensores, atuadores e lógica de controle em um único sistema.

## Desenvolvimento

O projeto foi desenvolvido e simulado integralmente no **Tinkercad**, permitindo testar o funcionamento do circuito, dos componentes e da lógica de programação antes de uma possível implementação física.
